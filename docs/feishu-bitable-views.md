# 飞书 Bitable 视图设计清单

> 飞书多维表格"活动库"的视图设计。
> 视图可通过 `POST /setup/feishu-views` 自动创建（幂等），也可按本文档手动创建。
> 字段定义与选项白名单见 `feishu-bitable-setup.md`。

## 视图总览（11 个，按使用频率排序）

| # | 视图名称 | 类型 | 用途 |
|---|---------|------|------|
| 1 | 本周活动 | Grid | 最常用：查看即将到来的活动 |
| 2 | 活动总表 | Grid | 默认视图：全量活动（排除过期/低保留） |
| 3 | 用户置顶 | Grid | 用户标记的重要活动 |
| 4 | 活动日历 | Calendar | 日历视图，按日期浏览 |
| 5 | 待审核看板 | Kanban | 按状态分列的审核流程 |
| 6 | 分类浏览 | Grid | 按活动类型分组（合并讲座/演出/比赛/招新） |
| 7 | 按公众号分组 | Grid | 按来源公众号分组查看 |
| 8 | 失败排查 | Grid | 排查抽取/同步失败的记录 |
| 9 | 已过期 | Grid | 已过期的活动 |
| 10 | 待确认时间 | Grid | 需人工确认时间的记录 |
| 11 | 活动归档 | Grid | 已归档活动，只显示基础信息（标题、日期、链接） |

## 操作步骤

### 自动创建（推荐）

```bash
curl -X POST http://localhost:8000/setup/feishu-views
```

自动创建/更新 11 个视图，幂等操作。

### 手动创建

1. 打开"活动库" Bitable
2. 右上 `+ 视图` → 选类型 → 配置名称、过滤、排序、分组
3. 按上面 11 个视图逐一创建
4. 把"本周活动"设为默认视图（右键 → 设为默认）
5. 把"活动日历"加到导航栏侧边快捷区
6. 收藏最常用的 3 个：本周活动 / 活动总表 / 用户置顶

## 排障

### 看板视图分组是空
"状态"字段必须是 SingleSelect。检查字段类型。

### 颜色规则不生效
飞书的颜色规则按"字段值"匹配，确认选项名与本文档 §活动类型选项 / §状态选项 / §时间状态选项 一致（含中点 `·`）。

### 日历视图打开是空白
开始时间字段必须是 DateTime 类型且时区为 Asia/Shanghai，参考 `feishu-bitable-setup.md` 字段总览。
