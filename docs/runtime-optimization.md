# 后台资源优化（2026-10-11）

本次保留双服务、PySide6 托盘、采集授权、OCR/Vision、飞书同步、日报/周报和机器人。Windows 自动启动仍然开启，修改已重启加载。

## 实测结果

测量对象为桌面管理器及其完整子进程树，不包括 Codex、浏览器和测试进程。单位为 MiB；以下为同机后台空闲快照，并非采集/OCR 的峰值。

| 指标 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 进程数 | 15 | 12 | 少 3 个 |
| 驻留内存（RSS 合计） | 539.6 | 488.2 | 少 51.4，约 9.5% |
| 私有提交内存 | 1203.7 | 386.9 | 少 816.8，约 68% |
| 整机 CPU 占用，1 秒采样 | 0% | 0% | 空闲时基本不耗 CPU |

私有提交内存表示进程申请并由系统承诺提供的内存，不等于当时实际占用的物理 RAM。RSS 合计可能重复计算共享库页面，也受 Windows 工作集回收影响。重启后的多次 RSS 为约 450–490 MiB，CLI 启动阶段的进程数会短暂变化。首次 OCR、导出文档和实际采集时占用会升高；尚未测量大批量任务的资源峰值。

## 已实施的改动

- 桌面管理器直接启动 Uvicorn，去掉常驻的 `start_service.py` 管理层；命令行启动脚本保留。
- 默认将 OpenBLAS、OpenMP、MKL、NumExpr 计算线程数设为 1，显式设置的环境变量仍优先。采集服务单独启动时也应用这些默认值。
- Pillow 和文档导出模块仅在扫码裁图、图片操作或导出时加载。验证 `import web` 后没有加载 NumPy、`PIL.Image` 和 `tools.mdtools.export`。
- RapidOCR 首次需要图片时加载，并在进程内复用一套模型；推理通过锁串行执行，避免多个采集线程同时创建模型或修改模型状态。下载、Vision 和飞书的并行处理保留。模型加载后保留到进程退出，避免每张图片重新加载。
- 手动更新和定时采集共用现有任务队列，对同一公众号的排队、运行和最近 5 分钟尝试进行去重。
- 微信返回 `200013` 时进入全局冷却：连续失败为 30、60、120 分钟，最多 120 分钟；成功响应重置失败计数。状态写入采集服务 `data/collection-state.json`，服务重启不会清除冷却。
- GoActivity 读取采集冷却/队列状态，避免重复触发以及无结果时持续等待 10 分钟。兼容没有该状态接口的旧版采集服务。
- 采集请求的 HTTP 200 业务错误不再被记为成功触发；冷却/去重响应记为跳过。
- Windows 停止服务或机器人时同时终止子进程；机器人异常退出增加退避与重试上限，合并读取 CLI 标准错误，避免管道堵塞。
- 关闭默认 SQL 逐条打印；删除认证密钥和扫码导航 token URL 的日志输出。需要排查 SQL 时可设置采集配置 `logging.sql: true`。

## 验证与当前限制

- GoActivity 全套测试：229 通过，在独立 SQLite 数据库中运行；测试关闭外部机器人和报告发送，使用 mock OCR/Vision。
- 采集服务测试：7 通过，覆盖二维码、去重、异常清理及持久化指数冷却。
- 真实 RapidOCR 图片识别输出 `Campus Activity 2026`，首次加载与识别共约 2.33 秒。
- 实机 `/health` 为 `ok`，所有必需定时任务均已注册，机器人处于运行状态。
- 微信授权有效至 `2026-10-15 16:49:29`。接口仍返回 `200013`，不能保证微信在冷却后立即解除限制；系统会在后续正常调度时按退避规则再次尝试。
- 实测一次采集触发了 30 分钟冷却，重复请求返回业务码 `42901`；第二次重启后冷却状态仍在。冷却期间完整 GoActivity 同步正常完成，无新增候选，无失败。
- 一项旧测试使用固定的 2026 年 7 月发布日期，现已超过 60 天过滤窗口；改用当前日期，使测试继续覆盖非活动宣传内容过滤。

## 再次测量

在项目根目录运行（`psutil` 已安装在采集环境）：

```powershell
.\we-mp-rss\.venv\Scripts\python.exe scripts\measure-runtime.py
```

脚本只输出进程名称、PID、内存、线程数与 CPU，不输出命令行或凭据。

新增采集状态接口：`GET /api/v1/wx/task-queue/collection/status`，沿用采集 API 的认证方式，返回冷却剩余秒数、重试时间、排队和正在运行的数量。
